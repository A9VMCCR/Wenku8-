# 查找书籍

在右上角打开搜索，输入关键词，不必输入完整书名。点击输入框右侧的筛选图标，可选择 **全部、书名、作者、标签、书籍 ID**；每个入口分别保留搜索范围。

## 发现：搜索已启用的书源

「全部」使用书源自身的搜索规则；「书名」进一步按返回的书名匹配。可以选择一个书源，也可以搜索全部启用且已配置搜索规则的书源。不同来源的同名书保持独立，不混用正文。向下滚动继续加载，返回后保留输入和已加载结果。

中文检索先保留原词，再补查不同的简体、标准繁体及港／台字形；不修改书源规则、原始书名或阅读内容。原词没有结果时继续查其他字形；已有结果时，补充结果随继续加载合并，按同一来源的书籍地址去重。不同字形分别保存分页位置，同时最多处理三个来源，不将界面语言当作搜索限制。英文和数字没有不同字形时只请求一次。

「作者」与「标签」使用已知书籍提供的原站作者／标签入口，或书源发现定义中的同名分类。来源没有提供相应入口时会明确提示，不把书名搜索结果冒充完整作者作品或标签书单。也可在详情页点作者、标签，直接打开其分页列表；是否存在下一页取决于来源规则和页面提供的分页信息，不限定为前 20 本。

## 书架、本地：查标签和自定义分类

书架默认检索已加入的书籍；开启「合并书架」后，也检索已缓存正文的书、本地原书与合订本。本地入口只检索导入书籍。支持：

- 书名片段、作者、书籍编号与已有标签。
- 本地入口及合并书架中的本地项可检索自定义分类名。
- 多个关键词，例如 `小舟 冒险`，要求每个词都能在这本书的元数据中找到。
- `#标签`，例如 `#校园 小舟`，其中「校园」只匹配标签或分类，不匹配书名。

中文匹配兼容简繁字形，英文不区分大小写，兼容全角字母、数字和常见分隔符，例如 `星海纪行` 可匹配「星海・紀行」。这里的模糊匹配是关键词包含匹配，不进行错字纠正或拼音推断。

详情页的标签可以点击，打开该标签的分页书单，与作者作品页使用同一套列表与加载交互。无网时只显示本机可离线阅读的已知书籍。标签来自服务元数据，接口未提供时不从书名或简介猜测。

## 合并书架：按来源筛选

书架筛选菜单提供两个独立条件：阅读状态和书籍来源。来源可选全部、本地导入、已缓存、在线收藏；其中「已缓存」指已有正文缓存的联网书，「在线收藏」包含已收藏的联网书。两个条件可以组合，立体书架、列表与书架搜索共享来源范围。关闭合并书架后恢复独立书架，不受此前来源筛选影响。离线和阅读器模式仍只展示可离线阅读的书。
