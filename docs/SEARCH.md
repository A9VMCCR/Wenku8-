# 查找书籍

在右上角打开搜索，输入书名的一部分或作者名字，不必输入完整书名。

## 发现：联网查书名和作者

发现页会同时查询书名与作者，合并并去掉重复书籍。向下滚动可继续加载结果；返回后保留输入内容和已加载结果。

## 书架、本地：查标签和自定义分类

书架只检索联网收藏，本地只检索导入的原书与合订本。支持：

- 书名片段、作者、书籍编号与已有标签。
- 本地入口可检索自定义分类名。
- 多个关键词，例如 `川原 冒险`，要求每个词都能在这本书的元数据中找到。
- `#标签`，例如 `#校园 川原`，其中「校园」只匹配标签或分类，不匹配书名。

英文不区分大小写，兼容全角字母、数字和常见分隔符，例如 `刀剑神域` 可匹配「刀剑・神域」。这里的模糊匹配是关键词包含匹配，不进行错字纠正或拼音推断。

标签检索适用于这两个入口，自定义分类仅在本地检索；发现的联网检索目前仍为书名和作者。
